PotatoDownload 推送测验平台

一键构造并发送 potato-vn://install 深链推送，验证插件的下载 → 校验 → 解压 → 入库全链路。直接用浏览器打开本文件即可（无需联网加载页面资源）。

前置条件

  1. PotatoVN 处于运行状态（窗口或系统托盘均可）。
  2. PotatoDownload 插件已安装并启用。安装方式：PotatoVN → 插件页 → 顶部「从本地压缩包安装」，选择你下载的 plugin.pvnplugin.zip。
  3. 除「仅提示」用例外，请确认插件设置中的「自动下载」为开启状态。
  4. 测试载荷托管于公共 echo 服务（默认 httpbingo.org），需要能访问公网。

发送历史

插件对 30 秒内完全相同的链接只处理一次；同一 provider + resource_id + checksum + url 的推送永久去重。预设用例和勾选「附加时间戳后缀」的自定义推送每次都会生成新 resource_id，因此总能被处理。

    在哪里观测结果

    ① 屏幕右上角弹条 / 通知铃铛：「开始下载」「完成」以及各类错误提示。

    ② PotatoVN 侧边栏「下载」按钮 → 弹窗内实时任务列表与进度条。

    ③ 游戏库：成功用例会新增一个游戏条目（按 bgm_id 刮削）。

    ④ 日志文件：PotatoVN 数据目录下 Logs\log.txt，含 PotatoDownload: 前缀的诊断记录（Warning 级别始终写入）。

    ⑤ 清理测试残留：删除游戏库中的测试条目；下载目录（默认为插件目录下 downloads\test_game\）可手动删除。

    协议参数速查（v1）

    参数必填说明
    v是协议版本，固定 1
    provider是^[a-z0-9._-]{1,64}$
    resource_id是资源唯一标识，≤256 字符
    url是http/https 直链，禁止本机/内网地址
    file_name是安全的单个文件名（不能含路径分隔符）
    archive_format是7z / zip / rar / tar / tar.gz / tar.bz2 / tar.xz / tar.zst
    size是文件字节数，>0
    checksum_algo + checksum成对sha256 或 blake3；64 位小写 hex
    expires_at是Unix 秒；过期后下载阶段报错
    bgm_id是Bangumi subject id，用于精确刮削
    title是游戏标题
    vndb_id / hikarinagi_id / archive_password否补充 ID 与压缩包密码
